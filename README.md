# AI Travel Assistant

AI Travel Assistant is a portfolio project for planning personalized trips with AI-assisted recommendations.

## Project Goal

This is a portfolio full-stack AI travel planning application that will generate personalized travel plans and packing recommendations based on a destination, dates, travelers, and contextual information such as weather.

## Planned Features

- [ ] Destination and trip dates
- [ ] Number of travelers
- [ ] Children/age ranges
- [ ] Weather-aware recommendations
- [ ] AI-generated itinerary
- [ ] AI-generated packing list
- [ ] Travel/visa requirements
- [ ] Saved trips
- [ ] Error/loading states
- [ ] Responsive UI
